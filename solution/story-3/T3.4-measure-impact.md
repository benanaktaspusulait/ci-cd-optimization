## 3. Local Measurement Commands

Run from the repository root after Maven has produced the required SNS target artefacts.

```bash
# Before: current Dockerfile
docker builder prune -af 2>/dev/null || true
time docker build --no-cache -t cmd-adaptor-sns:t3-before \
  -f cmd-adaptor-sns/Dockerfile cmd-adaptor-sns/ 2>&1 | tee /tmp/t3-before-cold.log
docker images cmd-adaptor-sns:t3-before
docker history --no-trunc cmd-adaptor-sns:t3-before | tee /tmp/t3-before-history.log

# After: candidate Dockerfile or .dockerignore change
docker builder prune -af 2>/dev/null || true
time docker build --no-cache -t cmd-adaptor-sns:t3-after \
  -f cmd-adaptor-sns/Dockerfile.layer-order-prototype cmd-adaptor-sns/ 2>&1 | tee /tmp/t3-after-cold.log
docker images cmd-adaptor-sns:t3-after
docker history --no-trunc cmd-adaptor-sns:t3-after | tee /tmp/t3-after-history.log

# Context transfer comparison
grep -E "transferring context|Sending build context" /tmp/t3-before-cold.log /tmp/t3-after-cold.log || true
```

Warm rebuild comparison:

```bash
# Before warm rebuild after artefact timestamp change
touch cmd-adaptor-sns/target/cmd-adaptor-sns-exec.jar
time docker build -t cmd-adaptor-sns:t3-before-warm \
  -f cmd-adaptor-sns/Dockerfile cmd-adaptor-sns/ 2>&1 | tee /tmp/t3-before-warm.log

# After warm rebuild after artefact timestamp change
touch cmd-adaptor-sns/target/cmd-adaptor-sns-exec.jar
time docker build -t cmd-adaptor-sns:t3-after-warm \
  -f cmd-adaptor-sns/Dockerfile.layer-order-prototype cmd-adaptor-sns/ 2>&1 | tee /tmp/t3-after-warm.log
```

Smoke checks:

```bash
docker run --rm --entrypoint sh cmd-adaptor-sns:t3-after -c \
  'java -version && envconsul --version && test -f /local/cmd-adaptor-sns-exec.jar && test -f /local/opentelemetry-javaagent.jar'
```

Optional Trivy report:

```bash
trivy image --severity CRITICAL,HIGH --exit-code 0 cmd-adaptor-sns:t3-after | tee /tmp/t3-after-trivy.log
```

## 5. CI Measurement Rules

CI impact can be recorded only if there is a real Drone after-run.

| CI metric | Before | After | Rule |
|-----------|--------|-------|------|
| CI elapsed duration | Average `13:35`, median `13:31` | TBC | Compare elapsed duration, not summed step durations |
| `Command Adaptor` step | Average `11:01` | TBC | Treat as cost concentration, not isolated Docker build |
| Failed/unsuccessful sample | 61.5% point-in-time reviewed sample | TBC | Do not treat as long-term KPI unless remeasured |

Do not claim exact CI elapsed-time reduction from local-only measurement.

## 6. Keep / Adjust Decision Rules

| Outcome | Decision |
|---------|----------|
| Lower context, same image behaviour, no smoke regression | Keep/propose `.dockerignore` route |
| Lower warm rebuild time, same image behaviour, no smoke regression | Keep/propose layer-order route |
| Image size lower only with new base image | Keep only after approved image-source, Artifactory, runtime and security checks |
| Faster build but smoke/Trivy/runtime regression | Adjust or reject |
| No measurable improvement | Do not promote; document as no-op |
