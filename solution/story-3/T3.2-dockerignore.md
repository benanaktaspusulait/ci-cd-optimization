## 1. Current State

T2.3 found no Docker ignore file in the SNS local checkout using:

```bash
find . -iname '*dockerignore*' -print
```

The current Dockerfile only needs:

```text
target/cmd-adaptor-sns-exec.jar

```

Therefore, `.dockerignore` is a valid Story 3 candidate, but it must retain these two artefacts.

## 3. Candidate .dockerignore

File location if repo-local ownership is confirmed:

```text
cmd-adaptor-sns/.dockerignore
```

Candidate content:

```gitignore
# Source is not needed by the current Dockerfile; Maven builds the JAR first.
src/

# Exclude generated output by default, but keep the runtime artefacts copied by Dockerfile.
target/**
!target/
!target/cmd-adaptor-sns-exec.jar
!target/dependencies/
!target/dependencies/opentelemetry-javaagent.jar

# Maven wrapper and build metadata are not used by the current Dockerfile.
.mvn/
mvnw

# IDE / editor
.idea/
.vscode/
*.iml
*.ipr
*.iws

# OS files
.DS_Store
Thumbs.db

# VCS and local noise
.git/
.gitignore
*.log
tmp/
temp/
.tmp/
```

Alternative deny-all pattern, if verified by a local Docker build:

```gitignore
*
!Dockerfile
!target/
!target/cmd-adaptor-sns-exec.jar
!target/dependencies/
!target/dependencies/opentelemetry-javaagent.jar
```

The deny-all version is stricter but should be used only after verifying Docker still receives every file the Dockerfile needs.

## 4. Verification

Run from the repository root after the required Maven artefacts exist:

```bash
# Baseline, before applying .dockerignore
docker build --no-cache -t cmd-adaptor-sns:before \
  -f cmd-adaptor-sns/Dockerfile cmd-adaptor-sns/ 2>&1 | tee /tmp/sns-build-before.log

# Candidate, after applying .dockerignore
docker build --no-cache -t cmd-adaptor-sns:dockerignore-candidate \
  -f cmd-adaptor-sns/Dockerfile cmd-adaptor-sns/ 2>&1 | tee /tmp/sns-build-after-dockerignore.log

grep -E "transferring context|Sending build context" /tmp/sns-build-before.log /tmp/sns-build-after-dockerignore.log
docker images cmd-adaptor-sns:before cmd-adaptor-sns:dockerignore-candidate
```

The candidate is acceptable only if:

- the Docker build succeeds;
- the context transfer is lower than the `191.27MB` before-state, or the result is explained;
- the final image still contains `/local/cmd-adaptor-sns-exec.jar`;
- the final image still contains `/local/opentelemetry-javaagent.jar`.

Example checks:

```bash
docker run --rm --entrypoint sh cmd-adaptor-sns:dockerignore-candidate -c \
  'test -f /local/cmd-adaptor-sns-exec.jar && test -f /local/opentelemetry-javaagent.jar'
```
