# T2.3 Docker Build & Image Baseline Commands

This file records the local commands used to capture the Docker build, image-size, build-context and layer baseline for `fdp-cmd-adaptor-sns`.

## 1. Check Maven Modules And Dockerfile Inputs

```bash
grep -n "<module>" pom.xml

grep -n "<profile>" pom.xml

grep -R "cmd-adaptor-sns-exec.jar\|opentelemetry-javaagent\|dependencies" -n \
  pom.xml \
  cmd-adaptor-sns/pom.xml \
  .drone.star \
  cmd-adaptor-sns/Dockerfile
```

## 2. Check Maven Plugin Configuration

```bash
grep -n "finalName\|spring-boot-maven-plugin\|maven-dependency-plugin\|maven-antrun-plugin\|copy-dependencies\|copy-rename-maven-plugin\|opentelemetry.version\|cmd-adaptor-sns-exec" \
  cmd-adaptor-sns/pom.xml \
  pom.xml
```

## 3. Build Required Maven Artefacts

```bash
mvn clean package -pl cmd-adaptor-sns -am -DskipTests
```

Alternative full build:

```bash
mvn clean install -DskipTests
```

## 4. Confirm Required Dockerfile Artefacts Exist

```bash
ls -lh cmd-adaptor-sns/target/cmd-adaptor-sns-exec.jar
ls -lh cmd-adaptor-sns/target/dependencies/opentelemetry-javaagent.jar
```

Expected paths:

```text
cmd-adaptor-sns/target/cmd-adaptor-sns-exec.jar
cmd-adaptor-sns/target/dependencies/opentelemetry-javaagent.jar
```

## 5. Search For Artefacts If They Are Missing

```bash
find . -name "cmd-adaptor-sns-exec.jar" -print
find . -name "opentelemetry-javaagent.jar" -print
find . -name "*javaagent*.jar" -print
find . -name "*exec.jar" -print
find . -type d -name "dependencies" -print
```

## 6. Docker Ignore Check

```bash
find . -iname '*dockerignore*' -print
```

## 7. Directory Size / Build Context Investigation

```bash

du -sh cmd-adaptor-sns/target/
du -sh cmd-adaptor-sns/src/
```

```text
Identify which directory contributes most to the Docker build context.
```

## 11. Docker Layer Breakdown

```bash

```

Purpose:

```text
Capture layer-level contribution such as base image, executable JAR, OpenTelemetry agent and yum install/update layer.
```

## 12. Full Re-Measurement Script

```bash
#!/bin/bash

IMAGE_NAME="cmd-adaptor-sns:baseline"

echo "=== Required Artefacts ==="
ls -lh cmd-adaptor-sns/target/cmd-adaptor-sns-exec.jar
ls -lh cmd-adaptor-sns/target/dependencies/opentelemetry-javaagent.jar

echo
echo "=== Docker Ignore Check ==="
find . -iname '*dockerignore*' -print

echo
echo "=== Directory Sizes ==="
du -sh cmd-adaptor-sns/
du -sh cmd-adaptor-sns/target/
du -sh cmd-adaptor-sns/src/

echo
echo "=== Docker Build Cold / No Cache ==="
time docker build --no-cache -t "$IMAGE_NAME" -f cmd-adaptor-sns/Dockerfile cmd-adaptor-sns/

echo
echo "=== Docker Build Warm / Cached ==="
time docker build -t "$IMAGE_NAME" -f cmd-adaptor-sns/Dockerfile cmd-adaptor-sns/

echo
echo "=== Docker Image Size ==="
docker images "$IMAGE_NAME"

echo
echo "=== Docker History ==="
docker history "$IMAGE_NAME"
```
